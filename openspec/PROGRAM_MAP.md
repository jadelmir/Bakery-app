# Bakery App Program Map

This is the durable, version-controlled traceability map for the product
roadmaps in [`Bakery_Production_and_Cost_App_PRD_v1.1.md`](../Bakery_Production_and_Cost_App_PRD_v1.1.md).
It complements, and does not replace, OpenSpec: active changes are the source
of truth for approved planned work and main specs are the synchronized
capability baseline. Product phases remain product milestones; agent work is
only an execution strategy within a change.

## Reading and maintenance rules

- **Program state** is one of `unmapped`, `proposed`, `active`,
  `implemented-unverified`, `verified`, `synced`, `archived`, or `blocked`. It
  describes delivery governance, not an application task lifecycle.
- An arrow (`A -> B`) means **A is an upstream prerequisite of B**. A phase can
  start planning before its prerequisite is complete, but cannot pass its PRD
  completion gate until all listed prerequisites and its own evidence gate are
  satisfied.
- `Synced` means the capability has a main spec and the cited change was
  synchronized; it does not claim the full PRD phase is complete. `Archived`
  in an evidence cell is immutable provenance, not permission to modify it.
- Update this map during proposal/update, after verification, at
  synchronization, and before archival. A failed lifecycle gate returns the
  change to **propose/update** or **apply** with the failed evidence recorded.

## Gated lifecycle

`audit -> propose/update -> apply -> verify -> sync -> archive`

| Gate | Required result | Failure return |
| --- | --- | --- |
| Audit | Roadmap, specs, changes, archive provenance, implementation, and evidence are compared. | Propose/update |
| Propose/update | One owning change has coherent scope, dependencies, non-goals, deltas, and tasks. | Propose/update |
| Apply | Approved bounded tasks are implemented with declared ownership. | Propose/update for scope/decision conflicts; otherwise apply |
| Verify | Acceptance, risk-appropriate quality, migration/security, and product checks are evidenced. | Apply |
| Sync | Verified deltas, main specs, task ledger, and this map agree. | Propose/update or apply |
| Archive | No required work remains; artifacts, evidence, synchronized specs, and map agree. | Propose/update or apply |
