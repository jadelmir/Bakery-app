# Legacy reference material

These files preserve the superseded pre-ORCH requirements documents exactly as they existed before this governance change. They are historical input/evidence for this OpenSpec change, not current durable documentation and not a source of truth.

OpenSpec remains the only source of truth for requirements, plans, tasks, progress, changes, and archives. Current implemented-system reference lives under `docs/`.

Do not restore these files to the repository root or `docs/` as canonical documents. Git history preserves the retired orchestration implementation itself; its code and delivery guide are intentionally not copied here.
